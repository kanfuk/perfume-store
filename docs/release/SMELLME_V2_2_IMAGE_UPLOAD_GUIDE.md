# Smellme v2.2 — carga masiva de imágenes

## Procedimiento para el cliente

1. Ingresa a **Admin**.
2. Abre **Catálogo**.
3. Selecciona **Carga masiva de imágenes**.
4. Selecciona la carpeta o el lote de imágenes.
5. Espera a que termine el matching.
6. Revisa las secciones **Coincidentes**, **Sin coincidencia** y **Ambiguos**.
7. No confirmes automáticamente una fila ambigua: asígnala manualmente al producto correcto o exclúyela del lote.
8. Confirma la subida.
9. Revisa el resumen final y reintenta únicamente los archivos fallidos si fuera necesario.
10. Comprueba las imágenes en el catálogo público.

## Nombres recomendados

Usa preferentemente uno de estos formatos:

- `SKU.jpg`
- `Marca Nombre Contenido.jpg`

Ejemplo:

`PACO-RABANNE-ONE-MILLION-EDT-50ML.jpg`

No es necesario renombrar un archivo cuando el preview ya lo asocia de manera inequívoca. Antes de subir, revisa siempre los casos ambiguos y los archivos sin coincidencia.
