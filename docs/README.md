# Pauli Store

**Pauli Store** es una aplicación web responsive para gestionar pedidos, ventas, costos y fiados de una minipyme casera.

La app tendrá dos partes:

1. **Formulario cliente:** vista pública compartida por WhatsApp.
2. **Panel administrador:** vista privada para Pauli y administrador.

## Stack sugerido

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase PostgreSQL
- Supabase Auth
- Vercel
- VS Code + Codex
